# 🧠 Bunerex's Stuff

¡Bienvenido al rincón caótico, creativo y experimental de **Bunerex**!

## 🤹‍♂️ ¿Qué es esto?

Un poco de todo y mucho de nada.  
Aquí encontrarás cosas que hago por **diversión, curiosidad y ganas de aprender**.

No esperes una IA revolucionaria.  
No esperes una app que cambiará el mundo.  
Espera... **cosas mías**.

## 🚀 ¿Para qué sirve?

Literalmente para **divertirme**. Si te ríes, aprendes o copias algo sin romper nada, pues doble éxito.

## 🛠️ Tecnologías

- Nada muy fancy, solo lo básico.  
- Quizás algo de HTML, scripts, o una IA que hace chistes malos (spoiler: no tan buena como yo).

## 🧾 ¿Cómo se instala?

No se instala. **Solo mira y disfruta**.  
Si algo se puede ejecutar, lo sabrás. O no.

## 🧪 ¿Cómo se usa?

 1. Abre un archivo.
 2. Intenta entender qué pasa.
 3. Hazte un café.
 4. Ríete un poco.
5. Si todo falla, di que es arte.
